# TON Avatar Generator (Telegram Mini App)

## 🚀 Запуск на локальном компьютере

1. **Установите зависимости:**
   Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
   Откройте терминал в папке с проектом и выполните команду:
   ```bash
   npm install
   ```

2. **Запустите режим разработки:**
   ```bash
   npm run dev
   ```
   После этого перейдите по ссылке `http://localhost:5173` (или другой, которую выдаст терминал) в вашем браузере. Вы увидите работающий интерфейс.

3. **Сборка проекта (для проверки перед деплоем):**
   ```bash
   npm run build
   ```
   Собранные файлы появятся в папке `dist`.

## ☁️ Деплой на Render.com

Чтобы ваш бот был доступен в интернете 24/7 и его можно было привязать к Telegram Web App, его нужно задеплоить. [Render.com](https://render.com) — отличный и бесплатный вариант для этого.

### Шаг 1: Подготовка на GitHub
1. Запушьте ваш проект (включая все изменения) в свой репозиторий на GitHub.

### Шаг 2: Создание веб-сервиса на Render
1. Зарегистрируйтесь на сайте [Render.com](https://render.com) (можно войти через GitHub).
2. Нажмите кнопку **New +** в правом верхнем углу и выберите **Static Site**.
3. Подключите свой аккаунт GitHub, если еще этого не сделали, и выберите репозиторий `avatar` (или как он у вас называется).
4. Настройте следующие параметры:
   - **Name:** Придумайте любое имя (например, `ton-avatar-bot`).
   - **Branch:** `main` (или та ветка, в которой у вас код).
   - **Build Command:** `npm run build`
   - **Publish directory:** `dist`
5. Нажмите кнопку **Create Static Site** внизу.
6. Подождите пару минут, пока Render соберет ваш проект. Как только процесс завершится, вы увидите зеленую надпись **Live** и ссылку вида `https://ton-avatar-bot.onrender.com`.

### Шаг 3: Подключение к Telegram Боту
1. Откройте Telegram и найдите бота **@BotFather**.
2. Если у вас еще нет бота, создайте его командой `/newbot` и получите его юзернейм.
3. Отправьте команду `/mybots` и выберите вашего бота.
4. Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
5. Укажите ссылку на ваш задеплоенный сайт с Render (например, `https://ton-avatar-bot.onrender.com`).
6. Теперь при нажатии на кнопку в боте у пользователей будет открываться ваша мини-апа (Telegram Web App), и она автоматически будет подтягивать их юзернейм!
